🔧 Column Mapper Tool

Map your legacy database columns to generate correct sync code

📋 How to Use This Tool

  1. Open http://localhost/ss/API/scan-legacy-tables-html.php in another tab
  2. Copy the column names from each table
  3. Paste them into the corresponding fields below
  4. Click "Generate Mapping" to see what needs to be updated
  5. Share the output with your developer
⚠️ Important: Paste ONLY the column names, one per line. Example:
id
bill_no
customer_name
email
phone
